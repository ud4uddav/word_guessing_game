# Word Guessing Game

A small beginner-friendly word guessing game written in Python. The computer chooses a secret word and the player has six chances to guess it.

## Live demo

Play the browser version here: **https://ud4uddav.github.io/word_guessing_game/**

## How to run the Python game

1. Install [Python 3](https://www.python.org/downloads/).
2. Clone or download this repository.
3. In a terminal, run:

```bash
python3 word_guessing_game.py
```

## What this project teaches

- Lists: storing the possible words.
- `random.choice()`: selecting a word at random.
- Variables: remembering the secret word and number of guesses.
- `while` loops: repeating the game while guesses remain.
- `if` statements: checking guesses and deciding what happens next.
- `input()`: getting text from the player.

The Python source has comments throughout to explain each part. `index.html` is a separate, simple browser version used for the live demo.
